MagicMaker · ESP32 transmitter

Web flasher

Put the MagicMaker transmitter firmware on a classic ESP32 or a Heltec WiFi LoRa 32 V3 straight from this page. Nothing to install.

Latest firmware Classic ESP32 · Heltec WiFi LoRa 32 V3 / V3.1 / V3.2

Install

  1. Plug the board into this computer with a USB data cable.
  2. Click Connect and pick the board's port (it shows up as CP210x, USB to UART or USB Serial).
  3. Click Install MagicMaker ESP32 transmitter. The page asks the chip what it is and picks the image itself: ESP32 gets the classic image, ESP32-S3 the Heltec V3 image. It erases the board and writes the firmware, which takes about a minute.
This browser can't open USB serial ports. Open this page in Chrome or Edge on a computer (Windows, macOS, Linux or ChromeOS), or in Chrome on Android with a USB OTG adapter. Safari and every browser on iPhone or iPad can't flash a board.
Flashing only works on a secure page. Open coral-coder.github.io/Magicmaker-mobile/flasher.

When it finishes, the board restarts and advertises as MM_ESP. In the MagicMaker app, choose the ESP32 transmitter backend and it links by itself. On a Heltec the screen stays dark until you press PRG.

What you need

  • Computer: Chrome or Edge on Windows, macOS, Linux or ChromeOS.
  • Android: Chrome with a USB OTG adapter or a USB-C to micro-USB / USB-C cable from the phone to the board. Older Chrome versions on Android can't open serial ports; if the button above says your browser isn't supported, use a computer.
  • iPhone / iPad: no browser there can reach a USB serial port. Flash the board once from a computer, then update it from the MagicMaker app over Bluetooth (below).

If it won't connect

  • Heltec V3: hold PRG, tap RST, release PRG, then click Connect again. If you flashed it this way, tap RST afterwards to start the new firmware.
  • Classic ESP32: hold BOOT while it connects and let go once writing starts.
  • No port in the list: install the USB driver, Silicon Labs CP210x VCP (Heltec V3 and most DevKits) or WCH CH340, then replug. Also try another cable: charge-only cables have no data wires.
  • Port busy: close anything else using it: the Arduino IDE serial monitor, flash.ps1 / flash.sh, or another tab with this page.
  • Linux: your user needs access to the port (add it to the dialout group, then log out and back in).

Update over Bluetooth from the iPhone

A board that already runs firmware 1.2 or newer can be updated from the MagicMaker iPhone app, no cable needed. The app carries firmware for both boards and can download a newer release from GitHub (CHECK WEB in its board firmware settings).

  1. Link the app to the board as usual.
  2. Press the board's button once: PRG on a Heltec V3, BOOT on a classic DevKit. For the next 2 minutes the board accepts an update; nobody can update it without that press.
  3. Start the firmware update in the app. The board checks the image, restarts into it and the app relinks. If anything goes wrong on the way, the board keeps running its current firmware.
